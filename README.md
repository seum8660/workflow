# 학교시설 업무 워크플로우 보드

기획부터 준공·사용승인까지, 학교시설 사업 담당자가 실제로 밟는 절차를 담당 주체(레인)와 단계 게이트로 갈라 놓은 웹 보드입니다. 설계변경·공기연장·인허가·안전사고 등 26개 업무를 같은 문법으로 읽습니다.

## 구성

| 파일 | 내용 |
| --- | --- |
| `학교시설 워크플로우 인트로.dc.html` | 표지. 26개 보드 폴더, 보드 읽는 법, 전주기 격자 도식 |
| `학교시설 워크플로우 보드.dc.html` | 본 보드. 26개 보드 전환, 전체 검색, 노드 상세 패널, 연결선·회귀선 |
| `학교시설 워크플로우 전자책.dc.html` | 쪽 넘기는 전자책. 좌측 개요·병목 / 우측 레인×단계 도식 |
| `data/wf_boards.js` | 보드 데이터 (노드·레인·단계·연결선) |
| `data/wf_tags.js` | 보드 이름 사전, 해시태그, 그래프 데이터 |
| `uploads/워크플로우/` | 세부 워크플로우 47장 (원본 HTML) |
| `support.js` | 페이지 런타임 |

## 사용법

정적 파일입니다. 저장소를 내려받아 `index.html`을 브라우저에서 열거나, GitHub Pages로 배포하면 바로 동작합니다.

```bash
git clone <repo>
cd <repo>
python3 -m http.server 8000   # http://localhost:8000
```

보드 조작:

- 좌측 목록에서 보드 전환, 상단 입력창에서 전체 보드 검색
- 노드에 마우스를 올리거나 클릭하면 연결선이 강조되고 신호가 흐름
- 클릭 시 하단 패널에 기한 · 법적 근거 · 필요 서류 · 병목이 열림
- 라이트 / 다크 / 웜 세 가지 화면 모드

전자책 조작: `←` `→` 키, 하단 버튼·슬라이더, 또는 책 아래쪽 좌·우 클릭.
